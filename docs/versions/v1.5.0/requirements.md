# v1.5.0 可读发行版本与升级兼容

- 对外版本为上游版本和二开发行序号：0.8.98-alpha.13；上游版本 0.8.98 单独显示。
- Android 内部 versionCode 仍严格递增，下一版 2026094013，不重置已安装版本的编号。内部构建号放版本详情。
- 新发布标签 v0.8.98-alpha.13，发布标题、APK versionName、更新弹窗、关于页与增量说明一致。旧 alpha-0.8.98-2026094012 继续作为可达基线；后续 alpha.14 从新 alpha.13 取增量。
- 发布日期独立读取对应实际发布记录的 published_at，日期不可用时显示未知，不按构建号猜日期。网络失败不阻止版本展示、下载及更新判断。
- 支持旧清单/旧标签，升级判断继续按内部构建号、包名、证书和 APK 哈希。
- 后续跟进上游时发行序号和内部编号都加 1；新上游版本不会把二开版本重新覆盖成裸版本。
- 保留 v1.4.0 日志保存周期全部实现及验收。旧需求 #191 已被本次版本规则改造取代，不继续旧发布。
- UI/普通工具由主会话实现；受保护发布配置经勾选授权的新 CNB 需求、开发助手、原生 CI、双审查与控制器推进。
