# 完成情况

状态：实现与本地验收完成；正式 PR、CI 与签名发布由仓库流程继续推进。文档里程碑 v1.1.0 不等于 APK 版本。

## 已实现

- 四个主页面的悬浮磨砂顶部工具栏、主操作材质和实际滚动采样。顶部 inset 包含系统状态区，避免 SafeArea 重复留白。
- 范围内的 CommonCard 使用统一内容面板、字阶、主题色和焦点边框；内容面板不逐卡模糊，不增加第二套业务状态。
- 首页新增组件、服务结果状态／地区标签与完整语义；配置了启动组件时不重复显示浮动启动按钮，编辑时隐藏浮动启动操作。
- 代理组磨砂切换条、节点选中标记／语义；配置选中标记与更多菜单保持可达；工具采用已有业务分组的内嵌面板。
- 检测弹层使用统一结果面板，原有成功、失败、取消及路由失效处理不变；网络输入和日志维持可读表面。
- 折射 shader 使用实际四角半径及物理尺寸，不把卡片强行当胶囊。
- 性能修正：删除每卡模糊阴影，避免已有按钮的重复裁剪；退出页面停止背景采样，返回时恢复。
