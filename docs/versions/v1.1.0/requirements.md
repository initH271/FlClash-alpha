# 内容层与操作层统一 UI

在 v1.0.0 玻璃导航基础上统一四个主页面。文档 v1.1.0 是设计里程碑，不等于 APK 版本。

- 浮动顶部工具栏和主操作使用真实局部模糊；折射支持实际圆角几何。
- 内容卡片使用轻表面，保留动态主题、已有圆角规范和文字可读性。
- 首页 13 个新增组件及既有组件保持用户配置和顺序；加入启动组件时避免重复浮动启动按钮。
- 代理组切换、节点选中、配置选中和工具分组具有一致结构；真实业务状态和生命周期仍由原有 provider/Core/ServiceState 负责。
- 服务检测结果统一状态和地区表达，成功/失败/取消/路由变化行为保持正确。

验收：既有测试不改，新测试验证滚动遮挡、点击、重复启动入口、选中语义及菜单；分析和相关测试通过。截图覆盖浅/深色、320/390、大字体、四语言、桌面、键盘、安全区、低效果；原生 Android 走查和帧时间独立记录。
