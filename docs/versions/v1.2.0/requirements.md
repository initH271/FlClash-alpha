# 导航细节与页面信息布局优化

文档 v1.2.0 表示 v1.1.0 后的 UI 优化阶段，不等于软件版本号。

- 优化手机底栏图标、文字比例、选中块与外框的圆角关系；保留导航语义、拖动预览和自定义图标。
- 首页状态、运行时间、上下行速率与连接摘要有明确层级，保留组件配置、顺序及原有启停行为。
- 配置页呈现 URL／文件分类、来源域名及已有订阅用量、到期／更新时间。
- 工具快捷卡压缩高度，图标与名称同行、说明一行；保留原有导航入口与设置分组。
- 代理卡减少留白，类型／当前线路说明与延迟同行；保留三种密度、tab／列表布局和原有选择／测试行为。
- 分组 tab 使用清晰的文字选中态、数量和细下划线，保留横向滚动及更多菜单。

验收：既有仓库测试不改；分析及相关测试通过；截图覆盖明暗、320/390/1100、1.4/2.8 字体、四语言、键盘、滚动与关闭效果；长分组和线路名称在三种密度、两种布局下不溢出。Android 原生组件走查验证页面、工具入口、分组切换及更多菜单。

不修改代理核心、模型／生成代码、依赖、用户配置、已保存的列数或密度选项。不把受控数据截图声称为真实代理验收。
