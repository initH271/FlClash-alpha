# v1.4.0 Core 日志时间保留与同负载实测

- Core 历史日志按记录时间过期，默认 14 天；提供 1、7、14、30 天与自定义正整数天数。
- 5 MiB 仍为分片大小，生产模式取消 20 片提前淘汰限制；未到期记录不因片数增加删除。
- 启动、定期清理、修改期限和导出均按期限处理，跨越截止点的分片只删除已过期记录。
- 配置持久化；初始化时直接使用保存的期限，避免选 30 天却先按 14 天清理；重连与连接期间变更同步最新设置。
- 旧配置缺失字段时默认 14 天；UI 校验自定义输入，不修改服务生命周期所有权。
- 同一 headless AVD、同一实际代理配置和本机回环 HTTP 源，INFO/DEBUG × 实时日志关闭/开启各重复三轮。
- 测量 CPU、内存、请求完成率、延迟、历史写入字节速率和队列丢弃；结果仅作为模拟器相对证据。
- 本期不统一改造 Flutter APP 的独立日志归档、不修改上游日志总线、不改自动化配置，不操作手机和本机代理。
